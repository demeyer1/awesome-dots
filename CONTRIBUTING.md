# Contributing

One pull request per project.

- Put it in the section it belongs to, at the end.
- One line: `[Name](link) - What it does, in one sentence.`
- It has to be about running or building dots-like agents, or one of the pieces
  they are made of.
- It has to exist and work: a public repository with a README, or a page that
  says what it is.
- Say what it does, not how good it is.
